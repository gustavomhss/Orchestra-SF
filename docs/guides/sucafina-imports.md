# Continuing an import in Sucafina

Open a preserved preview and follow its review link to continue reviewing that import. After an authorized import receipt is available, open the receipt or return to the import history. These links keep the same selected server, project and installation, including when several installations are available.

The links are available only while the current Sucafina context is ready and matches the displayed route. If access or the selected installation changes, open the import again from the current context. Each destination still checks access and reads its original source before displaying the review, receipt or history.
