## Cause and permitted correction

The installation's original environment (`modules/sucafina/Sucafinav1/local/entry.ts`) supplies a fresh real `at` at every call. Original Procurement `projectProcurementSource` computes exact fractional `ageDays` from that instant and the original approval-stage entry. C16 and the original source-link handler reread the canonical producer and strictly compare its complete values. A moving clock alone therefore changes BI06; BI05 counts do not have this field.

The CLI composition now holds only the first original observation time within one admitted UI BI06 invocation. It calls the original environment on every read and returns its current directory, key and ID function. No projection, source, result or authorization is cached, no age is rounded or removed, and no original producer/codec/grant/guard is changed.

The private invocation is bound to the same call, original Request and request metadata, binding digest, BI request digest, original operation and its original input digest. C16 can acquire the Request only after its original dispatcher consumes the admission. The source-link handler supplies its already-validated original bootstrap action and complete bootstrap input; it does not reinterpret that call as C16. The original host and environment/requestFor/revalidate/matchesIntent function identities are pinned for the invocation. Equivalent replacement functions are still rejected. Every synchronous boundary and final authorization await rechecks identity. `finally` closes both the invocation and collection-read scope; unrelated reads and later invocations use their own original clocks.

Only the BI collection callback activates this environment scope. Other Procurement consumers and other BI views retain their original observation behavior. A changed original collection, record, role, access revision, admission, selector, request or abort still fails through the original producer/authority fences or the additional private invocation check.

## Deliberate limit

`readForReview` is unchanged. Its original `sf_review_prepare` admission belongs to the complete agenda input, which is not passed to this BI consumer. Guessing a different operation or digest would weaken the original boundary. No review parser or authority interface was expanded. UI47–50 remain covered by their previously qualified sources.

Native non-UI capability calls also retain their existing path; this correction is scoped to the installed UI C16 and original UI bootstrap callers.
