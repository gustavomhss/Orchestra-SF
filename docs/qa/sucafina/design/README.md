# Sucafina nativa — inventário e primeira rodada de design

## Entrega para revisão

**Hoje (UI29), Casos/Decisões (UI33) e Dashboard Executivo (CAP01)** foram retrabalhados na identidade nativa do Orchestra. As capturas da aplicação real estão na [galeria visual](evidence/README.md); os resultados e limites da verificação estão em [VALIDATION.md](VALIDATION.md).

Branch: [`sf-design-polish`](https://github.com/gustavomhss/Orchestra-SF/tree/sf-design-polish), criada diretamente de `dev` em `948fab6ef2f8bbbcf2c8a6b787755a1d5713e6e1` e sincronizada com dev `39355aa1988b33653151ddc8b76bc2dac55e55dd`. Produto revisado: `41ea32b657ed2a9c170e544ac76ed6ecaaefe1ff`.

As dependências nativas #572 e #573 foram incorporadas à dev durante o trabalho. A branch de design inclui esse estado, mantendo os ajustes próprios isolados. O agente não alterou a branch compartilhada dev nem realizou os merges dessas dependências.

| Tela | Acabamento realizado |
| --- | --- |
| Hoje | Cartões de atenção/riscos alinhados; hierarquia de leitura, números e proveniência; retomada com título e ação confortáveis em telas estreitas; mensagens de disponibilidade completas |
| Casos / Decisões | Título, filtro e atualização na mesma faixa; registros e referências legíveis; campos alinhados; critérios numerados; revisão com ações claras e rodapé íntegro |
| Executivo | Navegação nativa discreta; KPIs e tabelas alinhados; controles de período acessíveis; revisão do editor organizada; contagem de usuários sem indicação monetária incorreta |

O trabalho foi dividido entre **três agentes reais**, um por tela, após a criação da branch e do inventário. Os commits e patches originais estão documentados em [WAVE-ONE.md](WAVE-ONE.md). A revisão das capturas gerou refinamentos adicionais antes da entrega.

O escopo visual continua restrito a essas três telas. A correção funcional mínima no editor compartilhado — necessária para impedir o ciclo reativo ao selecionar o mês — está explicada em [INTEGRATION.md](INTEGRATION.md). A interface legacy branca/verde e as telas nativas do núcleo HuGR não receberam redesign.

## Verificação

- **PASS**: fluxo real no Chromium, incluindo criação/revisão de caso e revisão/cancelamento/descarte do editor Executivo — [execução 44886474787](https://github.com/gustavomhss/Orchestra-SF/actions/runs/44886474787).
- **PASS**: tipos da aplicação, tipos E2E, regras do repositório e paridade dos sete arquivos de paleta — [execução 44886478223](https://github.com/gustavomhss/Orchestra-SF/actions/runs/44886478223).
- **17 capturas reais** versionadas na [galeria](evidence/README.md), com origem verificável no [manifesto](evidence/manifest.json).

As capturas usam dados isolados de teste e idioma inglês. A avaliação inclui desktop em claro/escuro, Casos/Executivo a 320 CSS px e Hoje a 390 CSS px, além de revisões inline. Isso não equivale a zoom real de 200%/400%, aprovação automática de baselines ou cobertura de todos os estados de todas as telas. Veja os limites completos no relatório.

A entrega está pronta para **revisão visual do usuário**. As outras **67 superfícies** estão inventariadas para as próximas rodadas.
