# Protótipos históricos de produto

Estes três artefatos preservam os conceitos de interface produzidos ao longo do trabalho. Usam dados de exemplo e não são implementação, teste, evidência de IA ou definição normativa do produto final.

- [Proposta inicial de produto](original-product-proposal.html).
- [Conceito de dossiê de decisão](original-decision-brief.html).
- [Mesa de decisão com IA](decision-workbench.html).

Os HTMLs são fragmentos de visualização. O escopo, as regras e o aceite executáveis são os do `campaign.json` e de seus documentos derivados no mesmo commit. Eventuais exemplos históricos divergentes não substituem esses contratos.
