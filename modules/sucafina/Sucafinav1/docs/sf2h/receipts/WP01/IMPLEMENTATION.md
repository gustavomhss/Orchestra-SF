- Record search consumes the existing authorized HTML of each canonical application, discovers pages only from the authorized sidebar, and extracts only records with existing identities or detail links. It pins the effective year/plan/period exposed by page controls, re-reads every contributing page, checks the final navigation scope, limits each read to 12 seconds, and revalidates on browser return. No snapshot API, direct state dump, fabricated reference, or persistent result cache was added.
- Scenario and contribution displays retain the distinction between known subtotal/difference and complete total/difference, show cost coverage references, expose omitted/pending categories and useful next steps, and retain the conditional choice history when later costs change.
- The analysis preparation boundary now uses the published `analysis.start` human permission, validates the selected profile/skill/version/manifest, checks the operation subset, validates producer output against the selected input schema, and revalidates access before returning. The optional local input seam fails closed when absent.
- The monthly HTTP boundary accepts the composed host's actual draft contract. Unpublished annual/entity requests are rejected before admission with `400 / needs-input / planner-operation-not-published`; they are not disguised as drafts or reported as successful operations.
