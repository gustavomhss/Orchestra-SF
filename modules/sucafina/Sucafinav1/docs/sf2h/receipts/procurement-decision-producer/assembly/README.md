## Human operation and effects

The form selects an attached authorized requisition, chooses either its current estimate or exactly one `replace` operation on `PR.estAmount`, captures a finite nonnegative amount, and shows the exact case currency and period. The human must explicitly select the renewal/transition inventory; the service converts that closed selection to the typed `procurement-cost-inventory` hypothetical assumption. No free-reference or JSON input is offered.

`procurement-scenario-controls` and `procurement-scenario-preview` use the new already-issued-scope reader. The reader and calculator use `commit: false` and never issue, refresh, execute, or revert a domain record. The preview route uses exact case state and a trusted current-case scope, avoiding the historical evidence reissuance path. A stale source is refused. The exposed `sf_scenario_simulate` Procurement branch also has no C08 write: the canonical handler returns its typed transient result and bound result receipt without inventing an output reference. `CapabilityResult.outputRef` is already optional in C16; no normative contract is changed. A transient result alone is not the persisted C15/native AM02 witness.

Saving uses the existing `decision-promote` human operation and C08 mutation. The form retains the original serialized payload and idempotency key before sending, permits only the same retry, and confirms a receipt only for the original case incarnation with version exactly incremented once and a result reference. Choice receives the saved scenario, result, source and C10 assessment through the existing ports. Source or target drift requires a new reviewed proposal.

Financial preparation is explicitly blocked. The independent scenario is useful for comparison but does not represent a financial approval. Current `Requests/save` admissibility and the formal approval workflow cannot be composed to approve and apply this new amount without a policy or command decision. The separate financial audit records that contradiction. No approval checkbox, second Apply, role, stage, threshold or engine change is part of this assembly.
