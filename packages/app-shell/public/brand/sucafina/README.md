# Authorized Sucafina identity assets

This directory is intentionally missing the trademarked logo artwork. Never recreate the Sucafina emblem or substitute HuGR marks in this deployment. The app falls back to plain **SUCAFINA** text until the brand owner supplies approved artwork.

Before the white-label is released, supply the approved, unaltered vectors:

- `lockup-inverse.svg` — full approved logo for dark surfaces
- `lockup-primary.svg` — full approved logo for light surfaces
- `mark-inverse.svg` — approved symbol for dark surfaces
- `mark-primary.svg` — approved symbol for light surfaces
- `favicon.svg` — approved favicon, and add it to the Sucafina HTML/PWA manifest

Verify exact artwork, padding, clearspace, aspect ratio, asset licenses and accessible contrast. The logo belongs to Sucafina, not the user-selectable theme. Do not publish a favicon or an official-logo claim before the approved originals are present.
