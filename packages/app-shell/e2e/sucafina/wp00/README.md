Raw observations distinguish a usable current business result from complete asserted business outcomes; they include failures without retries. Dashboard visual readiness requires the selected year's actual amount; Procurement requires the first identified request and its amount. These are automation-observed latencies, not compositor paint measurements.

`wp00-raw-measurements` and `wp00-server.log` are attached even if startup fails. A resident profile, missing service or other real bootstrap failure remains a failed test with zero successful UI measurements; the spec never bypasses that failure to manufacture observations.
